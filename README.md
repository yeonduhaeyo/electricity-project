기간/크기. 2024년 1–11월 약 32,064행(15분 간격) + 12월 예측 구간. (팀 내 공유 기준)

달력 정합성 & 기준연도

표기상 2024년이나 2월 29일 미관측 → 비윤년 판정.

2018·2019·2021·2022·2023 5개 연도와 주말/공휴일 패턴 일치도 비교 → 2018년이 가장 잘 맞아 기준 연도 채택.

자정(00:00) 롤오버: 일부 타임스탬프가 "다음날 00:00"으로 기록 → +1일 보정.

특정 시점 제거: 2018-11-07 00:00:00 1건만 제외.

EDA 하이라이트

시간·요일 패턴: 평일 > 주말; 공휴일은 요금 레벨이 낮아지는 경향.

부하 유형 영향: 작업유형에 따른 사용량/피크 타이밍 상이.

상관 구조: 전력사용량(kWh) ↔ 전기요금(원) 강한 양(+)의 상관, 지상–진상 역률은 음의 상관.

월별/계절성: 1월 최고·9월 최저(겨울·여름↑ / 봄·가을↓)의 계절성.

시간대 평균: 새벽 낮음 → 업무 시작 후 상승 → 야간 하락의 일중 패턴.

분포: 사용량·요금 모두 롱테일(피크일 존재).

전처리 원칙

시계열 정합성: 자정 롤오버/중복/결측 슬롯 보정, 캘린더 파생(요일, 공휴일, 분기, 주차, 시간대 비닝)

결측 처리: 수치형 ffill/bfill + 소량 보간, 범주형(작업유형) 최빈/직전값 대치

이상치 완화: 극단값 winsorization 옵션, 물리적으로 불가능한 값 제거

피처 설계 근거:

ACF: 1h·24h·7d·14d 반복성 → 최근·전일·전주 정보 활용

오후 피크(13–17시) 효과: +131% → 피크 플래그 유효

로그 변환: 롱테일 완화로 학습 안정화

파생 피처:

주기 인코딩: 24h/7d sine/cosine (연간 1년 데이터여도 일/주기 신호는 유효)

Lag/롤링: 1/4/8/96/672 lag, 4/96/672 이동평균, EMA

피크 더미: 오후/저녁/심야 플래그

🧠 모델링 전략 (2-Stage) & 검증

본 프로젝트는 2-Stage 파이프라인으로 최종 요금을 예측합니다.

Stage‑1: 보조 변수 복원(Feature Completion)

목표: test에 부재하거나 노이즈가 큰 6개 물리변수(전력사용량, 지상/진상무효전력량, 탄소배출량, 지상/진상역률) 예측·보강

모델: RandomForestRegressor

입력: 캘린더(요일/공휴일/월/주차/시간대), 주기성(sin/cos), 피크 더미, 작업유형(LE)

출력: 6개 변수의 예측값 → Stage‑2 입력으로 전달

Stage‑2: 최종 전기요금 예측

후보 모델: LightGBM, XGBoost, CatBoost, HistGradientBoostingRegressor(HGBR)

범주형 처리:

LGBM/CatBoost: season, 작업유형 카테고리 그대로

XGB/HGBR: .cat.codes 또는 Label Encoding 수치화

검증: TimeSeriesSplit(n_splits=3) → 마지막 폴드 홀드아웃 MAE로 선택

앙상블 선택:

단순 평균(블렌딩) vs 최고 단일 모델 중 홀드아웃 MAE가 낮은 쪽 채택

평가 지표: MAE (공식 제출 기준과 일치)

데이터 누수 방지: 모든 롤링/스케일/인코딩은 학습 구간 내에서 적합 → 검증/테스트에 변환만 적용.

상관/분포: 사용량–요금 강한 양(+) 상관, 지상–진상 역률 음의 상관; 사용량·요금 분포는 롱테일.

피처 설계 근거:

전처리 체계: 시간 라벨 표준화 → 주기(sin/cos)·시차(lag/rolling/EMA) → 품질/비율/프로필 →
OOF 보조변수(oof_kwh, oof_reactive, oof_pf)는 폴드 밖 예측만 사용하여 누수 차단.
